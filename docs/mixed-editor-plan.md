# 文本 + 表格混合编辑方案

> textarea → contenteditable div，右键插入表格，同一页面混合编辑。

---

## 一、最终用户交互

```
┌────────────────────────────────────────────────────┐
│  Note.ms/mynote                                [≡] │
│  无操作说明                                 插入表格│  ← flag + 插入按钮
├────────────────────────────────────────────────────┤
│                                                    │
│  这是一段普通的文字描述，可以和表格混排在一张纸上。 │
│                                                    │
│  ┌──────┬──────┬──────┐                            │
│  │ 姓名  │ 年龄  │ 城市  │  ← contenteditable 表格 │
│  ├──────┼──────┼──────┤                            │
│  │ 张三  │  28  │ 广州  │                            │
│  ├──────┼──────┼──────┤                            │
│  │ 李四  │  35  │ 深圳  │                            │
│  └──────┴──────┴──────┘                            │
│                                                    │
│  点表格格子直接编辑，不用敲任何格式符号。            │
│                                                    │
├────────────────────────────────────────────────────┤
│  ○ 已保存                                           │
└────────────────────────────────────────────────────┘
```

### 1.1 编辑纯文本
跟现在一样，直接打字，Enter 换行。

### 1.2 插入表格
两种方式：
- `.flag` 栏的 `[≡]` 按钮
- **右键 → 插入表格**

点击后弹出对话框输入**行数**和**列数**（默认 3×3），确定后在光标位置插入一个空表格。

### 1.3 编辑表格
- 点格子直接打字
- **Tab** → 跳到下一个格子
- **Shift+Tab** → 跳到上一个格子
- 头行自动加粗作为表头

### 1.4 右键菜单
```
┌─────────────────┐
│  插入表格         │
├─────────────────┤
│  在此行上方插入行  │  ← 光标在表格内时显示
│  在此行下方插入行  │
│  在此列左侧插入列  │
│  在此列右侧插入列  │
│  删除当前行        │
│  删除当前列        │
│  删除整个表格      │
└─────────────────┘
```

### 1.5 保存
自动保存（1 秒轮询，与现在一致），用户无感知。

## 二、存储格式

存进 `_tmp/xxx` 的内容是**纯文本**，表格以 Markdown 表格语法表示：

```
这是一段文字描述。

后面的文字也可以放在表格下面。
```

### 可读性

```
$ curl http://localhost:3000/mynote

这是一段文字描述。

| 姓名 | 年龄 | 城市 |
| --- | --- | --- |
| 张三 | 28 | 广州 |
| 李四 | 35 | 深圳 |

后面的文字也可以放在表格下面。
```

人眼可读，表格结构一目了然。

### 兼容性

- 非表格类纯文本笔记：完全不受影响，与现有存储格式一致
- 重新部署后旧笔记：照常显示为纯文本，不会有任何渲染异常

## 三、核心技术：序列化/反序列化

这是改动最核心的部分。

### 保存方向（div → 文本）

```
contenteditable div
         │
         ├─ 纯文本节点 → 原样输出
         ├─ <br>       → \n
         ├─ <div>       → \n（递归处理子节点）
         └─ <table>     → Markdown 表格语法（表格数据+分隔行）
```

### 加载方向（文本 → div）

```
存储文本
    │
    ├─ 以 \n 分行
    ├─ 检测以 | 开头的行 → 组成表格块
    │      └─ 跳过分隔行（| --- | --- |）
    │      └─ 其余行 → 渲染为 <table>
    └─ 非表格行 → 纯文本节点 + <br>
```

### 序列化示例

保存：

```js
serializeTable(document.querySelector('table'));
// →
// "| 姓名 | 年龄 | 城市 |
//  | --- | --- | --- |
//  | 张三 | 28 | 广州 |
//  | 李四 | 35 | 深圳 |"
```

加载：

```js
// 反序列化 Markdown 表格为 DOM
parseMarkdownTable(['| 姓名 | 年龄 | 城市 |', '| --- | --- | --- |', '| 张三 | 28 | 广州 |']);
// → <table>
//     <tr><th>姓名</th><th>年龄</th><th>城市</th></tr>
//     <tr><td>张三</td><td>28</td><td>广州</td></tr>
```

## 四、改动清单

### 4.1 `public/js/app.js` — 核心改动

| 改动点 | 说明 |
|---|---|
| `const textarea` → `const editor` | 指向 contenteditable div |
| `textarea.value` → `serialize(editor)` | 读内容改为序列化函数 |
| 新增 `serialize()` | contenteditable div → 带 Markdown 表格的纯文本 |
| 新增 `deserialize()` | 带 Markdown 表格的纯文本 → DOM 渲染 |
| 新增右键菜单 | 自定义菜单，插入/编辑/删除表格 |
| 新增表格插入 | 指定行列后插入 `<table>` 到光标位置 |
| 新增表格编辑 | 行列增删，Tab 跳格 |

改动量：约 **+200 行**（其中序列化/反序列化 ~60 行，右键菜单 ~60 行，表格交互 ~80 行）。

### 4.2 `public/css/style.css` — 样式增加

| 新增样式 | 说明 |
|---|---|
| `[contenteditable]` | 编辑区基本样式（继承现有 textarea 样式） |
| `#grid table` | 表格边框、折叠、宽度 |
| `#grid th` | 表头背景色、粗体 |
| `#grid td, #grid th` | 单元格间距、最小宽度 |
| `#grid td:focus, #grid th:focus` | 聚焦高亮 |
| `.ctx-menu` | 右键菜单定位、圆角、阴影 |
| `.ctx-menu button` | 菜单项样式 |
| 插入对话框 | 弹出层样式 |

改动量：约 **+50 行**。

### 4.3 `routes/notes.js` — 模板更新

| 改动点 | 说明 |
|---|---|
| `renderPage()` 模板 | `textarea` → `div contenteditable="true"` |
| 反序列化注入 | 首次加载时将文本中的 Markdown 表格转为 HTML |
| curl 输出 | 不需要修改，直接输出存储的原文本 |

改动量：约 **-5 行（删除 textarea）+ 30 行**。

### 4.4 无需改动的文件

| 文件 | 原因 |

## 五、边界情况

| 情况 | 处理 |
|---|---|
| 旧笔记（纯文本，无表格） | deserialize() 无 | 开头行 → 纯文本渲染，完全不受影响 |
| 光标位置没有选区 | 表格插在编辑区末尾 |
| 超大表格（20×20） | 表格在 layer 内可滚动，不会撑破页面 |
| 表格内粘贴 | 阻止粘贴 HTML，只保留纯文本 |
| 右键菜单在表格内 | 显示完整菜单（插入行/列、删除行/列、删除表格） |
| 右键菜单在表格外 | 只显示"插入表格" |
| 合并单元格 | 不支持（极简定位，不做复杂表格操作） |
| curl 读取含表格的笔记 | 直接输出带 Markdown 表格的纯文本 |
| contenteditable 光标丢失 | 用户点哪里编辑哪里，无需额外处理 |
