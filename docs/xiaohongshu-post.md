# 小红书推荐帖

---

**标题**：一个比记事本还轻的在线记事本，我用了两年

**正文**：

分享一个用了很久的小工具，没啥花里胡哨的功能，就是一张网页，打开就能写字。

它叫 Minimalist Web Notepad，名字够直白的。

不用注册，不用登录，打开网页就是全屏的文本框。敲完字直接关，它自己就保存了。下次在同一个链接打开，内容还在。

我主要这么用：

- 临时记个手机号、验证码、快递单号
- curl 当云剪贴板用，电脑之间传段文字很方便
- 写点临时草稿，不用开任何笔记 App

最近自己动手改了改，换成了 Node.js 版本，想加点东西也方便。存储支持本地文件或者 Vercel 上的 Redis，看部署在哪自动切换。

界面参考了 note.ms 的样子，白底 + 等宽字，看着不累。

如果你也经常需要"随手记点东西又不想要一个 App"，可以试试。
